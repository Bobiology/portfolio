# Sakawa Bob Elijah — Professional Resume Website

A lightweight, responsive, static portfolio website that can be hosted on GitHub Pages, Netlify, Vercel, cPanel/static hosting, or any web server.

## Included
- `index.html` — complete single-page resume/portfolio
- `assets/styles.css` — responsive styling
- `assets/script.js` — navigation and scroll animations
- `assets/profile.jpg` — current passport photo supplied for this version
- `assets/logo.svg` — personal SB logo
- Client projects section:
  - ECommerce Portal for Kisii Drompower Electronics, Nairobi
  - Website for Rainbow Therapies Kenya, Nairobi
  - ERP Implementation for Little Angels School, Namanga

## Hosting
Upload the contents of this folder to the public web directory of your hosting provider. The site has no server-side dependencies.

## Notes
The current passport photo is intentionally used as supplied. It can be replaced later by overwriting `assets/profile.jpg` with the improved image.
